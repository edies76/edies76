---

## Lunar

A learning AI that actually understands pedagogy — not a chatbot with a study mode. Persistent learning state. Diagnostic reasoning. Adaptive routing. Built on an Orchestrator protocol, Anchors system, and dual-agent architecture.

Live at [bambalunar.app](https://bambalunar.app)

**Key layers:**
- Study Routes (agentic learning guidance)
- Spaces (semester-long infrastructure)
- MicroChats (focused conversations at passage level)
- Dual agents: primary (reasoning) + Grok (vision/research)

Why it matters: not a tool you open once—infrastructure for an entire learning period that remembers where you are in every topic.
